# taskmanager
# Консольный менеджер задач

Простой и удобный консольный менеджер задач, написанный на Python. 
Проект создан для быстрого управления повседневными делами прямо из терминала.

## Особенности (Features)
- **Сохранение данных:** Задачи сохраняются в текстовый файл (`tasks.txt`) и не пропадают после закрытия программы.
- **Защита от ошибок (Уракоустойчивость):** Программа не ломается, если ввести букву вместо цифры или попытаться удалить несуществующую задачу.
- **Чистый интерфейс:** Использование модуля `os` для автоматической очистки экрана терминала, чтобы меню всегда оставалось аккуратным.

## Требования
- Установленный Python 3.x
- Стандартные библиотеки (встроенные, установка не требуется)

## Как запустить
1. Запустите скрипт task_manager.py
